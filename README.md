# Meridian Retail Analytics

This repository contains a synthetic retail transaction dataset prepared for a business intelligence analysis exercise.

## Dataset

- File: `odin_synthetic_retail_sales.csv`
- Period: 1 January–30 June 2026
- 180 transaction-line records across four fictional business locations and five product categories
- All records are synthetic and do not represent a real business or real customers.

## Disclosure

AI-generated before recording.

The dataset is intended for demonstration and analytical practice only.
